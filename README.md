# CarRent — Система аренды автомобилей

> Учебный Проект на WPF + MSSQL. 

---

## Описание

Приложение для аренды автомобилей. Пользователь может авторизироваться в систему, просматривать доступные машины, фильтровать их по параметрам, бронировать понравившийся.

Администратор может добавлять, редактировать и удалять автомобили из системы.

---

## Технологии

- **Язык:** C#
- **Платформа:** WPF
- **База данных:** MSSQL (через Entity Framework)

---

## Функционал

### 1. Авторизация и регистрация
- При запуске открывается окно входа
- Пользователь вводит логин и пароль
- Данные хранятся в БД
- Роли: **Пользователь** и **Администратор**
- Возможность войти как **Гость** (без бронирования)

### 2. Главная страница с автомобилями
- После входа открывается главная страница
- Отображаются карточки автомобилей (фото, марка, модель, цена в день, статус: доступен / занят)
- Доступные автомобили подсвечены зелёным, недоступные — красным
- **CRUD для админа:** кнопка "Добавить автомобиль" видна только администратору

### 3. Поиск и фильтрация
- Поле поиска по марке или модели автомобиля
- Фильтры:
  - По цене (минимум / максимум в день)
  - По типу кузова (седан, внедорожник, хэтчбек и т.д.)
  - По статусу (только доступные)
- Результаты обновляются сразу при изменении фильтров

### 4. Карточка автомобиля (детальная информация)
- При нажатии на карточку открывается детальная страница
- Показывается подробная информация:
  - Фото, марка, модель, год выпуска
  - Тип кузова, цвет
  - Цена за день
  - Описание
  - Статус (доступен или нет)
- Если машина доступна — кнопка **"Забронировать"**
- Для администратора — кнопки **"Редактировать"** и **"Удалить"**

### 5. Бронирование автомобиля
- Пользователь выбирает **дату начала** и **дату окончания** аренды
- Система автоматически считает **итоговую стоимость** (кол-во дней × цена/день)
- После выбора дат — переход на страницу подтверждения
- После подтверждения бронирование сохраняется в БД
- Статус автомобиля меняется на "Занят"
- Пользователь переходит на страницу оформления

### 6. Панель администратора (управление автомобилями)
- Доступна только пользователям с ролью "Администратор"
- **Добавить** новый автомобиль (заполнить все поля + загрузить фото)
- **Редактировать** существующий автомобиль (все поля + смена доступности + смена фото)
- **Удалить** автомобиль (с подтверждением)

### 7. Выход из системы
- Кнопка "Назад" возвращает на предыдущую страницу
- На странице авторизации кнопка "Назад" скрыта

### 8. Оформление контактных данных
- После выбора дат пользователь вводит Email и номер телефона
- Система сохраняет заявку на бронирование
- Менеджер свяжется с пользователем для подтверждения
- После подтверждения отображается QR-код

## Структура базы данных

### Таблица `Users` (Пользователи)
| Поле | Тип | Описание |
|------|-----|----------|
| ID | int (PK) | Уникальный ID |
| FirstName | string | Имя |
| LastName | string | Фамилия |
| Login | string | Логин (уникальный) |
| Password | string | Пароль |
| Role | string | "User" или "Admin" |

### Таблица `Cars` (Автомобили)
| Поле | Тип | Описание |
|------|-----|----------|
| ID | int (PK) | Уникальный ID |
| Brand | string | Марка (BMW, Toyota...) |
| Model | string | Модель |
| Year | int | Год выпуска |
| BodyType | string | Тип кузова |
| Color | string | Цвет |
| Price | decimal | Цена (руб.) |
| Description | string | Описание |
| Image | string | Имя файла фото |
| Available | bit | Доступен ли |

### Таблица `Rentals` (Бронирования)
| Поле | Тип | Описание |
|------|-----|----------|
| ID | int (PK) | Уникальный ID |
| UserID | int (FK) | Ссылка на пользователя |
| CarID | int (FK) | Ссылка на автомобиль |
| StartDate | DateTime | Дата начала |
| EndDate | DateTime | Дата окончания |
| TotalPrice | decimal | Итоговая сумма |
| Status | string | "Active" / "Completed" / "Cancelled" |

## Окна / Страницы приложения

```
LoginPage            — Вход в систему / гостевой вход
MainWindow           — Главная оболочка (шапка, подвал, навигация)
CarsPage             — Список машин + поиск + фильтры
CarDetailWindowPage  — Детальная карточка машины
BookingWindowPage    — Форма бронирования (выбор дат, расчёт стоимости)
ContactDetailsPage   — Оформление контактных данных (Email, телефон, QR-код)
AdminPage            — Добавить новый автомобиль
EditCarPage          — Редактировать существующий автомобиль
```

## Как запустить

1. Склонировать репозиторий
2. Открыть `CarRent.sln` в Visual Studio 2022
3. Восстановить NuGet пакеты (ПКМ на проекте → Restore NuGet Packages)
4. Настроить строку подключения в `App.config` под свой SQL Server
5. Восстановить БД из бэкапа в SSMS
6. Запустить проект (F5)
